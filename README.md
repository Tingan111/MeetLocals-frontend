# MeetLocals
本專案為團隊專案之個人前端作品整理版本。

MeetLocals 是一個以「在地體驗」為核心的旅遊網站，讓使用者可以探索不同地區的特色活動與旅遊行程。

網站內容涵蓋 **6 大體驗分類**與 **6 個地區**，使用者可以透過分類、地區及商品資訊快速找到感興趣的在地體驗。

## 功能

* 會員註冊／登入
* Google 登入
* 商品瀏覽與篩選
* 購物車功能
* 商品評價留言系統
* 部落格系統
* 一對一客服聊天室

## 我負責的內容

* **首頁切版**：依照設計稿完成首頁 RWD 響應式介面
* **RESTful API 串接**：串接後端 API 取得資料，並將資料呈現於首頁
* **一對一客服聊天室**：負責前後端串接與即時訊息功能，讓會員與客服可以進行一對一文字及圖片訊息溝通
